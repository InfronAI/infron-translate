Meeting Assistant

Transcript, translation, and summary in one overlay

The meeting assistant captures microphone and current Chrome tab audio, sends collected audio windows to StepFun HTTP + SSE ASR, and updates transcript and summary panels during the call.

1Start the assistant from the popup
2Enable mic or tab audio input
3Review live transcript and translations
4Refresh meeting insights every 60 seconds or 6 turns
Install

Run it locally as an unpacked Chrome extension

git clone https://github.com/InfronAI/infron-translate.git
cd infron-translate
npm install
npm run build

Open chrome://extensions, enable Developer mode, choose Load unpacked, and select the generated dist/ directory.
