Infron Translate

A Chrome extension for full-page webpage translation, bilingual reading, and lightweight AI meeting assistance.

View on GitHub Install from source
Page Translation

Detect source language and translate the current webpage in bilingual or translation-only mode.

Cloud Models

Use Chrome built-in translation or OpenAI-compatible model providers.

Meeting Assistant

Capture mic and tab audio, generate transcripts, translations, and periodic summaries.

Translation

Built for everyday reading workflows

Language controls

Auto-detect the page language, then manually adjust both source and target languages.

Two display modes

Read bilingual comparison text or replace source text in place with translation-only mode.

Engine choice

Switch between Chrome built-in translation and configurable OpenAI-compatible cloud models.

Site-aware controls

Pause translation per site and toggle automatic webpage translation with the floating logo button.

Meeting Assistant

Transcript, translation, and summary in one overlay

The meeting assistant captures microphone and current Chrome tab audio, sends collected audio windows to StepFun HTTP + SSE ASR, and updates transcript and summary panels during the call.

1Start the assistant from the popup
2Enable mic or tab audio input
3Review live transcript and translations
4Refresh meeting insights every 60 seconds or 6 turns
Install

Run it locally as an unpacked Chrome extension

git clone https://github.com/InfronAI/infron-translate.git
cd infron-translate
npm install
npm run build

Open chrome://extensions, enable Developer mode, choose Load unpacked, and select the generated dist/ directory.
