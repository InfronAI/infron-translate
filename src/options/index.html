需要配置

服务商

选择一个服务商预设，然后确认端点和模型。

端点

远程端点需使用 HTTPS。本地 localhost HTTP 可用。

API 密钥

存储在 chrome.storage.local。保存时留空会保留已保存的密钥。

推理强度

较低推理强度通常能提升翻译速度。

会议转录

配置会议助手实时音频转录使用的 ASR WebSocket 连接。

WebSocket 连接

用于实时全双工音频转录的 WebSocket 地址，默认使用 StepFun ASR Stream，并走系统代理。

转录模型

用于实时 ASR 的模型，默认使用 StepFun 推荐的 stream 模型。

转录 API Key

仅用于会议助手音频转录。保存时留空会保留已保存的密钥。

网站规则

管理不应自动启动网页翻译的网站。

暂停网站

使用英文逗号分隔域名，也可在扩展弹框中暂停当前网站。
